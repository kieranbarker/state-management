# State Management

A simple demonstration of three ways to manage state in React.

1. [Passing props](https://react.dev/learn/sharing-state-between-components) (see the `main` branch)
2. [Reducer and Context](https://react.dev/learn/scaling-up-with-reducer-and-context) (see the `reducer-and-context` branch)
3. [Zustand](https://zustand.docs.pmnd.rs/getting-started/introduction) (see the `zustand` branch)
